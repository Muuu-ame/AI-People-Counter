# AI People Counter

YOLOによる人物検出と人物追跡を利用した、入場者統計システムの開発プロジェクトです。

人物の入場人数を集計し、顔が十分に検出できる場合には年齢層や性別の推定を行うことを目指しています。

## 概要

* 人物検出による入場者カウント
* 人物追跡による二重カウントの抑制
* 年齢層の推定
* 性別の推定
* 集計結果の可視化
* 映像を保存しない運用を目指した設計

※ 開発中のプロジェクトです。各機能の実装状況や精度は、今後の検証によって更新します。

## セットアップ

### 1. リポジトリを取得

```powershell
git clone <リポジトリのURL>
cd AI-People-Counter
```

### 2. 仮想環境を作成

```powershell
python -m venv .venv
```

### 3. 依存ライブラリをインストール

`requirements.txt` が用意できたら、次のコマンドでインストールします。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 4. 起動

```powershell
.\.venv\Scripts\python.exe main.py
```

初回起動時には、使用するモデルのダウンロードが必要になる場合があります。

## プライバシーへの配慮

本プロジェクトでは、映像を保存せずに人物検出・統計処理を行う構成を目指しています。

実際の運用では、必要な集計値だけを保存し、顔画像や個人を特定できる情報を不必要に保持しない方針です。

年齢層や性別の推定は誤差を含むため、判定できない場合は「不明」として扱うことを想定しています。

## 制約事項

* 人物の重なりや混雑により、人数を正確に数えられない場合があります。
* 顔の向き、照明、解像度によって属性推定の精度が変化します。
* 推定された年齢や性別は、本人の実際の属性を保証するものではありません。
* 実際の設置環境で精度を検証する必要があります。
